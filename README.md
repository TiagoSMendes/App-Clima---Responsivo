# App Clima — Responsivo

Aplicativo de clima feito com HTML, CSS e JavaScript puro. Digite uma cidade (ou use sua localização) e veja o tempo agora.

## Funcionalidades

- Temperatura atual, mínima e máxima do dia
- Sensação térmica, umidade e vento (em km/h)
- Descrição do tempo em português com ícone
- Bandeira do país e estado/região
- Botão "usar minha localização"
- Fundo que muda conforme o tempo (sol, chuva, neve...) e à noite
- Atalhos para cidades sugeridas
- Responsivo e com mensagens de erro claras

## API

Usa o [Open-Meteo](https://open-meteo.com/), que é gratuito e **não precisa de chave de API**.
Assim, nenhuma chave fica exposta no código público. Bandeiras vêm do [flagcdn.com](https://flagcdn.com/).

## Rodando

Abra `App - Clima/index.html` no navegador.
